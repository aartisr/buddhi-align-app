# Buddhi Align Practice Guide

The best way to start with [Buddhi Align](https://buddhi-align.foreverlotus.com/) is to choose one small, meaningful step.

## Plan

Use the [Dharma Planner](https://buddhi-align.foreverlotus.com/dharma-planner) to define a purpose-aligned intention and a practical next action.

## Practice

Choose the module that fits the day: [Karma Yoga](https://buddhi-align.foreverlotus.com/karma-yoga) for service, [Dhyana Meditation](https://buddhi-align.foreverlotus.com/dhyana-meditation) for meditation notes, [Bhakti Journal](https://buddhi-align.foreverlotus.com/bhakti-journal) for gratitude and devotion, or [Jnana Reflection](https://buddhi-align.foreverlotus.com/jnana-reflection) for inquiry and study.

## Reflect and review

Observe recurring patterns in the [Vasana Tracker](https://buddhi-align.foreverlotus.com/vasana-tracker), then use [Motivation Analytics](https://buddhi-align.foreverlotus.com/motivation-analytics) for a calm view of practice consistency. For the official framework and FAQ, visit [About Buddhi Align](https://buddhi-align.foreverlotus.com/about).
