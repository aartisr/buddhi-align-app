# Publishing the Buddhi Align Wiki

**Author:** [Aarti S Ravikumar](https://ai-aarti.com/)

The canonical Wiki source is maintained in this repository so its content can be reviewed, tested, and published consistently.

## Where it is published

- [Web edition](https://aartisr.github.io/buddhi-align-app/wiki/): a searchable, accessible GitHub Pages edition with canonical URLs and Article structured data.
- [GitHub Wiki](https://github.com/aartisr/buddhi-align-app/wiki): synchronized from this source after the repository Wiki feature is enabled.
- [Documentation home](https://aartisr.github.io/buddhi-align-app/), [practice guide](https://aartisr.github.io/buddhi-align-app/practice-guide.html), and [official sources](https://aartisr.github.io/buddhi-align-app/open-web-reference.html): supporting Pages that link back to this Wiki.
- [Source repository](https://github.com/aartisr/buddhi-align-app): the reviewed source for the app, wiki, PWA, and discoverability operations.

## Editorial workflow

1. Update a Markdown file in `docs/wiki`.
2. Review links, author attribution, and public-safety language.
3. Merge to `main`. GitHub Pages builds the web edition, and the Wiki sync workflow publishes the same Markdown to GitHub Wiki.

The live product remains the authoritative source for current functionality, support, and account-related information.
